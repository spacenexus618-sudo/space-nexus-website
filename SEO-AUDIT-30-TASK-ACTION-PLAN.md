# SEO Audit 30-Task Action Plan

> Generated: 8 Sep 2026
> Skill: seo-audit
> Goal: Identify and fix SEO issues to improve organic search performance

---

## Phase 1: Crawlability and Indexation (Tasks 1-7)

Task 1: Check robots.txt to ensure important pages are not blocked and verify sitemap reference is correct.

Task 2: Verify XML sitemap exists, is accessible at /sitemap.xml, and contains only canonical indexable URLs.

Task 3: Run site:spacenexus.net search to compare indexed pages vs expected page count.

Task 4: Check for noindex tags on important pages that should be indexed in search results.

Task 5: Verify all pages have self-referencing canonical tags pointing to the correct URL.

Task 6: Check for redirect chains or loops that waste crawl budget and slow indexing.

Task 7: Identify soft 404 pages returning 200 status code instead of proper 404 response.

---

## Phase 2: Technical Foundations (Tasks 8-14)

Task 8: Test Core Web Vitals using PageSpeed Insights to check LCP INP and CLS scores.

Task 9: Check server response time TTFB and optimize if above 600ms threshold.

Task 10: Verify all images use modern WebP format and are compressed for faster loading.

Task 11: Check lazy loading implementation on images below the fold to improve initial load.

Task 12: Test mobile responsiveness with proper viewport configuration and no horizontal scroll.

Task 13: Confirm HTTPS across entire site with valid SSL certificate and no mixed content warnings.

Task 14: Verify URL structure uses lowercase hyphen-separated readable descriptive URLs.

---

## Phase 3: On-Page Optimization (Tasks 15-22)

Task 15: Audit all title tags for uniqueness proper length 50-60 characters and primary keyword placement.

Task 16: Check meta descriptions for uniqueness proper length 150-160 characters and compelling call to action.

Task 17: Verify heading hierarchy with one H1 per page containing primary keyword and logical structure.

Task 18: Confirm primary keyword appears in first 100 words of each page content.

Task 19: Check image alt text for descriptive content that accurately describes each image for accessibility.

Task 20: Audit internal linking to ensure important pages are well-linked with descriptive anchor text.

Task 21: Identify orphan pages with no internal links pointing to them and add relevant links.

Task 22: Check for keyword cannibalization where multiple pages target the same primary keyword.

---

## Phase 4: Content Quality (Tasks 23-26)

Task 23: Assess E-E-A-T signals including experience expertise authoritativeness and trustworthiness on key pages.

Task 24: Check thin content pages with little unique value and plan content expansion or consolidation.

Task 25: Verify content depth is comprehensive answers follow-up questions and outperforms competitors.

Task 26: Confirm all content is accurate properly sourced and recently updated with current information.

---

## Phase 5: Monitoring and Reporting (Tasks 27-30)

Task 27: Review Google Search Console coverage report for indexation errors warnings and exclusions.

Task 28: Check for manual actions security issues or penalties in Google Search Console.

Task 29: Set up monthly SEO monitoring checklist for ongoing health checks and performance tracking.

Task 30: Create prioritized fix list ranked by impact and effort for immediate actionable improvements.

---

## Expected Results

Fixing crawlability issues ensures Google can find and index all important pages efficiently.

Technical improvements boost page speed and Core Web Vitals scores for better ranking signals.

On-page optimization increases relevance for target keywords and improves click-through rates.

Content quality improvements enhance user engagement reduce bounce rates and build authority.

Regular monitoring prevents issues from going unnoticed and maintains ongoing SEO health.

---

## Validation Checklist

All pages pass Google Mobile-Friendly Test with no errors.

No critical errors in Google Search Console Enhancements reports.

Core Web Vitals pass in PageSpeed Insights for key pages.

All title tags and meta descriptions are unique optimized and compelling.

Internal linking structure connects all important pages within 3 clicks of homepage.
