# Newly Added Skills & Agents to SpaceNexus

Added on: 7 Sep 2026

## New Skills (11)

### SEO & Content

The `schema-markup` skill adds JSON-LD structured data to pages when you need rich snippets in Google. The `copywriting` skill improves headlines, CTAs, and landing page copy when pages are not converting. The `copy-editing` skill polishes and refines existing copy when content needs cleanup. The `competitor-alternatives` skill creates vs/alternative comparison pages when you want to rank for competitor keywords.

### Conversion Optimization (CRO)

The `page-cro` skill optimizes any page for conversions when conversion rates are low. The `signup-flow-cro` skill optimizes signup and registration flows when users are dropping off at signup. The `form-cro` skill optimizes contact and demo forms when forms are not getting submissions.

### Analytics & Tracking

The `analytics-tracking` skill sets up GA4, GTM, and event tracking when you need to track user behavior.

### Marketing

The `ab-test-setup` skill plans and runs A/B tests when you want to test page changes. The `email-sequence` skill creates email nurture campaigns when you need email marketing flows. The `social-content` skill creates social media content when you need LinkedIn or Twitter posts.

## New Agents (11)

The `seo-optimizer` agent is an on-page SEO specialist. The `content-analyzer` agent provides data-driven content analysis. The `meta-creator` agent handles meta title and description generation. The `internal-linker` agent manages internal linking strategy. The `keyword-mapper` agent performs keyword placement analysis. The `editor` agent makes voice and tone improvements. The `headline-generator` agent handles headline creation. The `cro-analyst` agent focuses on conversion rate optimization. The `performance` agent handles performance analytics. The `cluster-strategist` agent manages topic cluster strategy. The `landing-page-optimizer` agent focuses on landing page optimization.
